## NVIDIA 公司史

| 時間 | 事件 | 戰略意義 |
|------|------|----------|
| 1992 年底 | 在聖荷西 Berryessa Road 的 Denny's 與 Malachowsky、Priem 商議創立公司 | 公司起源傳說，後來 NVIDIA 視 Denny's 為「聖地」。 |
| 1993/04/05 | NVIDIA 正式成立，初始資本 $40,000 | 原名 NVision，發現名字被衛生紙廠商註冊後改為 NVIDIA。 |
| 1995 | 推出 NV1（多媒體 PCI 卡，搭配二次曲面與遊戲手把支援） | 失敗——押錯架構，業界轉向三角形與 DirectX。公司瀕臨倒閉。 |
| 1997 | 推出 Riva 128（NV3），支援 DirectX / OpenGL | 救命之作，首四個月賣破 100 萬片；扳倒 3dfx。 |
| 1998 | 推出 Riva TNT（首款 multi-texturing 3D 處理器）；總部從 Sunnyvale 搬到 Santa Clara | 確立繪圖核心地位。 |
| 1999/01/22 | IPO 於 NASDAQ，每股 $12 | 募資加速成長。 |
| 1999 | 推出 GeForce 256，首次定義「GPU」概念（整合 T&L） | 創造產業類別；至今市場仍沿用 GPU 一詞。 |
| 2000 | 收購 3dfx 智慧財產 | 收編宿敵。 |
| 2006/11 | 發表 CUDA（與 GeForce 8800 GTX 同步） | **關鍵戰略轉折**：讓 GPU 變成通用平行運算引擎；當時市場無人理解，市值從 $120 億跌到 $20-30 億。 |
| 2008/07 | 因行動晶片組製造缺陷認列 $2 億減值 | 後有集體訴訟（涉及 Apple、Dell、HP 筆電）；2010/09 和解。 |
| 2008 | 推出 Tegra（移動晶片）；金融海嘯下股價腰斬 80% | 行動戰略試水溫，後來證明失利。 |
| 2012/09 | AlexNet 使用兩顆 GTX 580 在 ImageNet 大幅勝出 | **AI 時代開端**；Hinton 與 Sutskever 證明 GPU 是深度學習的關鍵硬體。 |
| 2016/04 | 發表 DGX-1（首款 AI 超級電腦） | 把「AI 超算」打包成單一產品。 |
| 2016/08 | Jensen 親手把首台 DGX-1 送到 OpenAI，並簽名「To Elon and the OpenAI Team! To the future of computing and humanity」 | 與 OpenAI 結盟、深度學習正統化的象徵時刻。 |
| 2019/03/11 | 宣布以 $6.9B 收購 Mellanox | 押注 data center networking（NVLink 母體）；至當時是公司史最大併購。 |
| 2020/04/27 | Mellanox 收購正式完成 | 構成日後 AI factory 網路骨幹。 |
| 2020/05 | 推出 Ampere 架構 A100 | 為 GPT-3 等大模型訓練奠基。 |
| 2020/09 | 宣布以 $40B 收購 ARM（向 SoftBank） | 想統一 CPU+GPU+IP 帝國。 |
| 2022/02 | ARM 收購失敗，認列 $1.25B 違約金 | 監管壓力（FTC / EU / 中國）逼退；後改採投資+授權路線。 |
| 2022/03 | GTC 發表 Hopper 架構（H100） | Transformer Engine 為 LLM 而生。 |
| 2022/11/30 | ChatGPT 發布 | 引爆 H100 的需求海嘯；訂單交期飆到 36-52 週。 |
| 2023/05/30 | 市值首破 **$1 兆**（盤中） | 加入兆元俱樂部；第五家美國公司。 |

## 思想 / 風格轉折點（推測 + 證據）

- **1980s（AMD/LSI 時期）**：技術人，學會晶片設計工藝與業界 ecosystem。
- **1993-1999（早期 NVIDIA）**：戰術型 CEO，從 NV1 失敗中學會「面對殘酷現實、戰略性撤退」（後在 NTU 演講重述）。
- **2000-2005（GeForce 黃金期）**：產業領袖，建立「年度節奏」與「平台思維」。
- **2006-2012（CUDA 黑暗期）**：佈道者，獨自押注 GPU 計算十年，承受市值腰斬與華爾街質疑。**個性最重要的鍛造期。**
- **2013-2017（深度學習黎明）**：開始穿固定皮衣，建立「Jensen」品牌形象；首次以 keynote 取代 PPT 風格。
- **2018-2022（資料中心轉型）**：從 graphics CEO 變身 accelerated computing CEO。
- **2023-2024（AI 帝王時刻）**：成為全球最受矚目的科技 CEO；論述從技術轉向哲學（pain and suffering, character、first-principles）。
- **2025-2026（地緣政治關鍵人）**：從企業家變成「半個外交官」，在中美間走鋼絲；同時推 Physical AI 為下一個十年。

## 最近 12 個月動態（2025/07 - 2026/06）★務必更新

> 防止 Skill 過時的關鍵段落。

### 市值與股價
- **2025/10/29**：市值首破 **$5 兆**，全球首家。
- **2026 上半年**：股價持續走高；Jensen 個人身家於 **2026/05/14** 首次突破 **$2,000 億**，登上 Forbes 全球第 7-8 富豪（在 Bernard Arnault、Michael Dell 之上）。NVIDIA 市值約 **$4.7 兆**（依即時數據浮動）。
- **2026/03 月文件**：Jensen 個人 + 家族信託持有約 **3-3.3%** NVIDIA 股權。

### 產品 / 路線圖
- **Blackwell Ultra（B300/GB300）**：2025 H2 起量產，記憶體 1.5×、頻寬 2×。
- **Vera Rubin**：2026/06/01 GTC Taipei 宣布全面量產，Vera CPU 替換 Grace；首批雲端：AWS、Google Cloud、Azure、Oracle、CoreWeave、Lambda、Nebius、Nscale。
- **Rubin Ultra**：2027 H2，Kyber NVL576 機架，單 GPU ~100 PFLOPS NVFP4、1TB HBM4e。
- **Feynman**：2028，Rosa CPU（3D die-stacked）。
- **Physical AI / Cosmos**：2025 CES 推出後成為新戰略軸；機器人與自駕車為目標市場。
- **Project DIGITS**：2025/05 開賣，$3K 起的桌面 AI 超算。

### 中國 / 地緣政治
- **2025/04**：H20 出口被禁，認列 $5.5B 減值。
- **2025/07**：Trump 政府放行，恢復出貨（Jensen 親自遊說）。
- **2025/08**：北京以「後門」疑慮反限；商務部長 Lutnick「第四好晶片」言論激怒北京。
- **2026/05**：Trump 訪中國名單未含 Jensen（含 Tim Cook、Musk）。
- **2026/05/21**：Jensen 公開稱已「大致放棄」中國 AI 晶片市場給華為。
- **2026/06/08**：拒絕參議院銀行委員會聽證邀請。
- **2026/06**：Nvidia 年度中國營收缺口估約 **$50B**。

### 演講 / 媒體
- **2026/06/01**：GTC Taipei 2026 keynote（兩小時），台灣定位為「AI 震央」，公布台灣總部 Constellation 校區、每年投入 $1500 億。

### 私人生活
- 與 Lori 結婚邁向 41 週年。
- 兒子 Spencer 任 NVIDIA Senior PM；女兒 Madison 任 NVIDIA Marketing 總監。
- Jen-Hsun and Lori Huang Foundation 持有逾 **6,900 萬股** NVIDIA。
- 持續被工程師迷弟迷妹拍照、簽 T-shirt、簽女生胸口（爭議性訊息，2024 起多次媒體討論）。

### 主要爭議
- **管理風格**：「demanding」「torturous」「perfectionist」標籤；50 位直屬部屬（一般 CEO 約 10 位）。Jensen 自己承認且引以為榮。
- **中國立場矛盾**：一邊警告「華為勝出將是 horrible outcome」，一邊在北京清華擔任顧問。
- **政商分寸**：未受邀同 Trump 訪中；拒絕國會聽證。
- **股票分割後股權集中度**：個人身家高速膨脹引發財富不均討論。
