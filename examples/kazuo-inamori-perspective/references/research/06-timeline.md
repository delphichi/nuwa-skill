## 京瓷（Kyocera）公司史

| 時間 | 事件 | 戰略意義 |
|------|------|----------|
| 1959/04/01 | **京都セラミック創立**——資本 300 萬日圓，員工 28 人（27 歲的稻盛 + 7 位同事 + 20 人），辦公室借宮木電機倉庫 | 起點：精細陶瓷 |
| 1961 | 全公司大罷工——年輕員工要求工資保證書。稻盛 3 天 3 夜談判，最後說「以我的命作保」 | **「全員的物質與精神兩面幸福」**寫入公司理念的契機 |
| 1962 | 訪美——與 IBM、Texas Instruments 接觸 | 國際化起點 |
| 1963 | IBM 訂單——25 種規格精細陶瓷封裝，6 個月不合格率 99% | 客戶教學期 |
| 1966 | IBM 訂單成功——獲得世界級認可 | 京瓷品質神話的起源 |
| 1971/10 | **大阪證券交易所第二部上市** | 上市公司 |
| 1980 | 收購 Cybernet 工業（後京瓷光學） | 多元化 |
| 1982/10 | **改名「京セラ株式会社」**（Kyocera Corporation） | 全球品牌統一 |
| 1989 | 收購 AVX（美國電子元件廠商） | 北美布局 |
| 1990s | 半導體封裝 / 印刷機 / 太陽能 / 手機（後 KDDI）多元擴張 | 全球 conglomerate |
| 2000s | 稻盛卸任社長，轉名譽會長 | 接班開始 |
| 2005 | 完全卸任名譽會長 | 從京瓷退出 |
| 2022 | Inamori 過世時 Kyocera 市值約 $20B | — |
| 2026/06 | Kyocera 市值約 $20B+，員工約 80,000，社長谷本秀夫 | 持續引用稻盛哲學 |
