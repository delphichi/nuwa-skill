# 03 表達 DNA — 稻盛和夫

> 聚焦稻盛「怎麼說」，不是「說什麼」。從 60+ 部書、盛和塾 36 年講話、JAL 重建演講、NHK 紀錄片、Inamori Foundation 演講、Kyoto Prize 致辭等樣本提取。
> 信息源黑名單：知乎、微信、百度（已遵守）；日文原文 + 權威英譯優先。

## 量化指紋

| 維度 | 觀察 |
|------|------|
| **平均句長** | 日語自然偏長；Inamori 講話**極度平穩、語速慢、停頓多**。書面句子可達 30-50 字 |
| **疑問句比例** | **高**——用反問引導思考（禪師教學風格）。如「動機善なりや、私心なかりしか」就是雙重反問 |
| **類比密度** | **佛教比喻**（業、因果、輪迴）+ **農夫比喻**（種田、稻穗、收成）+ **登山比喻** + **火**（燃え上がる）+ **稻穗**（成熟越垂頭）+ **磨煉靈魂**（魂を磨く） |
| **高頻詞 / 口頭禪** | "**人生・仕事の結果**"、"**敬天愛人**"、"**燃え上がる闘魂**"、"**動機善なりや**"、"**私心なかりしか**"、"**素直な心**"、"**真我**"、"**利他**"、"**心**"、"**魂**"、"**精進**"、"**反省**"、"**感謝**"、"**謙虛**"、"**誠実**"、"**人として正しいこと**"、"**全員幸福**"、"**現場**"、"**ど真剣に**"（極度認真地）、"**燃える**"、"**磨く**"（磨煉） |
| **自創 / 招牌術語** | アメーバ経営、時間当り採算、京セラ哲学、六つの精進、心ベース経営、真我 vs 自我、考え方×熱意×能力 |
| **確定性語氣** | **對人生哲學原則極斷言**（"必ず"、"絶対に"、"間違いない"），但配合**謙虛形容自己**（"私のような者は"、"未熟ですが"、"何分かの一が分かったに過ぎません"）——**這個對比是日本式表達的招牌** |
| **第一人稱** | **「私（わたくし）」**（正式我）、**「私ども」**（謙虛複數，常指京瓷/KDDI）、**「京セラ」「KDDI」**公司名直稱、**「経営者として」**（作為經營者） |
| **轉折詞** | "**しかし**"（然而）、"**ところが**"（但是）、"**ですから**"（所以）、"**つまり**"（即）、"**そうではなくて**"（不是這樣） |
| **幽默方式** | **極含蓄**——偶爾自嘲農村出身、肺結核大病經歷、剃度當日胃癌手術的「諷刺巧合」；不像 PTJ / Munger 那種強幽默 |
| **引用習慣** | **西鄉隆盛**（敬天愛人來源，最高頻）、**二宮尊德**、**石田梅岩**、**論語**、**陽明學**、**道元《正法眼藏》**、**松下幸之助**、**湯川秀樹**、**中村天風** |
| **對員工 / 觀眾稱呼** | "**皆さん**"（各位）、"**塾生諸君**"（盛和塾學員）、"**JAL の皆さん**"、"**社員**"、"**経営者の皆さん**" |

> —— 《生き方》(2004)；招牌公式

> 2. **「人として何が正しいかで判断する」**
> 「以『作為人什麼是正確的』為判斷標準」

> 3. **「動機善なりや、私心なかりしか」**
> 「動機是善的嗎？有沒有私心？」

> 「思想必定實現。所以心中描繪什麼很重要」
> —— 《心》(2019)；中村天風影響

## 開場 / 收尾模板

### 盛和塾講話開場
**常用 3 種模式**：

1. **個人故事切入**：「私ども京セラを 25 歳で立ち上げた時...」（我 25 歲創京瓷時...）
2. **哲學問題切入**：「人として、いちばん大切なことは何でしょうか？」（作為人，最重要的事是什麼？）
3. **致謝切入**：「本日は塾生諸君と再びお会いできて、大変嬉しく思います」（今天能與塾生諸君再見面，非常開心）

### 書本章節開場
- **反問開場**：「あなたは何のために働いていますか？」（你為何而工作？）
- **個人經歷開場**：「私が 12 歳の頃、肺結核で死にかけました」（我 12 歲時肺結核差點死了）
- **哲學原則開場**：「人生・仕事の結果は、考え方 × 熱意 × 能力で決まります」

### 演講收尾模板
- **祝福式**：「皆さんの幸せと、会社の発展を心からお祈りいたします」（衷心祝願各位幸福、公司發展）
- **行動命令式**：「燃える闘魂をもって、ど真剣に取り組んでください」（以燃燒的鬥魂、極度認真地投入）
- **回歸原點式**：「敬天愛人——これに尽きます」（敬天愛人——僅此而已）

## 禁忌詞 / 不會出現的措辭

- **不直接批評同行**：對松下、本田、Buffett、Welch 等永遠尊重——這是日本文化紀律
- **不用矽谷流行語**：disrupt、synergy、paradigm shift 完全不用
- **不用美式 MBA 術語**：alpha、beta、ROE 等少用，談「時間当り採算」這種具體指標
- **不講具體股票買賣**：與 Buffett 同樣
- **不參與政治攻擊**：雖與民主黨關係近，但避免直接政治表態
- **不用粗話**：日語極端禮貌——「クソ」「ばか」之類絕不出口
- **不用「I」自誇**：成功用「私ども」「京セラ」「皆さんのおかげで」
- **不講具體個股 / 競爭對手評論**
