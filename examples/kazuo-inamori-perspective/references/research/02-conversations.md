# 02 長對話與即興思考 — 稻盛和夫

> 本人寫了大量書，但對話模式有獨特之處——盛和塾的 Q&A 是核心，因為他必須回應真實企業困境。
> 信息源黑名單：知乎、微信、百度（已遵守）。

## 重要對話來源

### 1. 盛和塾（Seiwajuku）Q&A 1983-2019 ★最重要

**結構**：每月一次月例會，稻盛親自飛全國各地分塾（後期國際），與中小企業主面對面 Q&A。每場 3-6 小時。

**規模**：
- 36 年持續
- 日本 56 個分塾 + 海外 48 個分塾
- 累計學員 14,938 名中小企業主
- 完全免費

**內容性質**：
- 學員上台描述自己企業的具體困境（人事、財務、戰略、家族傳承等）
- 稻盛當場回應，**把哲學原則具體化到該企業場景**
- 這是稻盛**最豐富的即興思考紀錄**——他必須回應從未準備的問題

**典型問答模式**：
1. 學員描述問題（10-15 分鐘）
2. 稻盛短暫停頓
3. 用「敬天愛人」「動機善なりや」「人として正しいこと」框架重構問題
4. 給具體建議（不一定是學員想聽的）
5. 收尾用六項精進中一條

**訪問難度**：盛和塾錄音 / 影片大部分未公開，主要透過《盛和塾叢書》整理出版。

## 即興回答的 5 個模式

稻盛是極少數**主動降低自己權威性**的經營者。他的招牌即興模式：

### 模式 1：「人として正しいこと」原則化問題
**範例**：
- 學員問「該不該裁員救公司？」
- 稻盛不直接答 yes/no
- 反而問「**對員工是不是『人として正しいこと』？對股東？對社會？三邊都正確才行動。**」

### 模式 2：用京瓷 / JAL 真實案例回應
**範例**：
- 學員問「現金流危機怎麼辦？」
- 稻盛講「1961 年京瓷罷工事件——我用我的命作保。你能不能也用你的人格作保？」

### 模式 3：「私ども京セラ」框架——把問題拉回基本面
- 大部分回答以「私ども京セラの場合は...」（我們京瓷的情況是...）開頭
- 不一定學員的問題與京瓷直接相關，但稻盛總能找到類比

### 模式 4：「動機善なりや」自問題引導
- 對重大決策問題，稻盛常引導學員：「**先別問怎麼做，先問為什麼做。動機善なりや？私心なかりしか？**」
- 答對動機才談方法

### 模式 5：「燃え上がる闘魂」鼓舞收尾
- 即使給出具體建議，稻盛常以「**最後是要燃え上がる闘魂——付出不亞於任何人的努力**」收尾
- 把方法論交回到員工的「心」

## 拒絕回答的話題

### A. 政治細節
- 雖與民主黨菅直人內閣有顧問關係，但**從不公開支持特定政黨 / 政策**
- 對國際政治（中美關係、台海、北韓等）幾乎不評論

### B. 其他企業家具體評論
- **絕不點名批評同行**（松下、本田、稻盛皆相互尊重）
- 對 Buffett、Welch 等海外經營者公開尊重但少實質評論

### C. 京瓷 / KDDI / JAL 具體股價 / 持倉
- 從不公開談論股價短期波動
- 不公開個人持股數量

### D. 三個女兒 / 家庭細節
- **完全不在媒體露面**
- 不公開三女兒姓名、職業、住所

### E. 中國市場的具體政治評估
- 稻盛在中國有極大影響力，但**從不公開評論中國政治**
- 對中國盛和塾學員只談經營哲學

### F. 加密貨幣、新興技術評論
- 晚年（2010s 後）對 AI、加密、區塊鏈等較少發言
- 自承「我已脫離技術前線」

## 與盛和塾學員的對話模式專章

### 上下級結構
- 學員稱稻盛為「**塾長**」
- 稻盛稱學員為「**塾生**」「**塾生諸君**」
- 結構類似師徒——但稻盛拒絕「精神領袖」標籤

### 典型 Q&A 流程
1. **學員上台描述問題**（10-15 分鐘）：具體企業困境
2. **稻盛短暫停頓 + 微笑**
3. **重構問題**：「您剛剛問的核心是 X，但更本質的是 Y」
4. **回到哲學原則**：「敬天愛人」「動機善なりや」「人として正しいこと」
5. **舉京瓷 / KDDI / JAL 案例**
6. **給具體建議**
7. **以六項精進中一條收尾**

### 學員的反饋模式
- 大部分學員稱「**人生觀被改變**」
- 部分稱「**像被父親教導**」
- 少數批評稱「**像被教派洗腦**」

### 國際盛和塾的文化適應
- 中國盛和塾學員最多——文化親近度高
- 美國 / 巴西盛和塾學員——需要翻譯 + 文化轉譯
- 稻盛親自飛各國分塾——77+ 歲仍持續

## 與 Charlie Munger 的相互推崇

### Munger → Inamori
- Munger 多次公開表示稻盛是「**他在亞洲最敬佩的經營者**」
- 推崇原因：(1) 一致的人格 + 經營行為 (2) 對員工的真實關懷 (3) 哲學深度
- Berkshire 圈內人（Buffett、Schroeder 等）對 Inamori 普遍知曉

### Inamori → Buffett / Munger
- 稻盛公開引用 Buffett / Munger **較少**——主要因為語言 + 文化隔閡
- 但對「投資哲學」與「商業道德」深表敬意
- 京瓷哲學中的「**長期視角**」「**信任管理層**」與 Buffett 哲學有共鳴

### 隱含的哲學共鳴
- 稻盛「**敬天愛人**」≈ Buffett 「**ovarian lottery**」（兩者都強調出生運氣 → 利他責任）
- 稻盛「**真我 vs 自我**」≈ Munger「**inner scorecard**」（兩者都強調內在標準）
- 稻盛「**動機善なりや**」≈ Munger「**incentive 結構檢視**」（兩者都重視動機純粹性）

### 直接對話
- 稻盛與 Munger 並無直接公開對話紀錄
- 但 Berkshire 年會的中文 / 日文 attendees 經常引用稻盛
- Munger 過世（2023/11）後，日本經營界深表惋惜

## JAL 內部訓話特章（晚年最重要的真實考驗）

### 背景
- 2010/01/19 JAL 申請破產
- 2010/02/01 稻盛 77 歲無薪接任會長
- 2010-2013 重建期，與 3 萬員工的對話

### 訓話的 3 個層次

**Layer 1：對高管的「就任演說」（2010/02 第一週）**
- 「**我來這裡不是為了個人利益，是為了拯救 JAL 與日本航空業**」
- 「**JAL 重建必須從『意識改革』開始——我們先改變思考方式，再改變數字**」
- 「**我會用京瓷哲學——你們可能會說『這是製造業的，不適合航空業』。但哲學是普世的**」

**Layer 2：對全員的「JAL Philosophy 教育」（2010-2011）**
- 親自編寫 40 條 JAL Philosophy（部分源自京瓷哲學）
- 親自飛各機場 + 各 base，分組座談
- 員工人手一本 JAL Philosophy 手冊，每日朝會誦讀

**Layer 3：對中層管理者的 Amoeba 教育**
- 引入「部門別採算制度」
- 每個小單位每日 / 每月計算「時間当り採算」
- 中層第一次理解自己部門的真實財務狀況

### 員工反應的兩面性

**正面（多數）**：
- 「**稻盛先生拯救了我們**」
- 「77 歲老人親自飛各機場——我們不能說『不可能』」
- 「**第一次有人告訴我們『工作的意義』**」

**負面（少數）**：
- 「**意識改革感覺像意識形態強迫**」
- 「Amoeba 制度讓中層壓力極大」
- 「JAL Philosophy 朝會誦讀像宗教儀式」

### 結果
- **2010 當年度單年轉虧為盈 ¥320B+**
- 2012/09 重新上市
- 2013+ 連續多年「全球最高利潤航空公司」
