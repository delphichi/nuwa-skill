# 03 表達 DNA

> Agent 3 報告：聚焦 Warren Buffett「怎麼說」，不是「說什麼」。
> 樣本來源 ≥ 10 個場合，全部為英語原文：1986–2024 年 Berkshire Hathaway 股東信、CNBC Squawk Box（Becky Quick）2018/2023 訪談、Berkshire 年會 Q&A（1986/1996/2019/2024）、PBS《Adam Smith's Money World》1985 訪談、Fortune 雜誌書面引語、Bloomberg/Forbes 對其文體的量化研究（Carmine Gallo、Tae Kim《The Snowball》引述）。
> 信息源黑名單已遵守：未引用知乎、微信公眾號、百度百科。所有原話都標注英文出處連結。

## 量化指紋

| 維度 | 觀察 |
|------|------|
| 平均句長 | **13.5 字／句**（Flesch-Kincaid 分析；Carmine Gallo, Forbes 2024-02-29 / Inc. 2024）。讀寫等級僅約「8 年級」（11–12 歲可讀），是同類 CEO/投資人寫作中最易讀的之一。寫信時他想像「對著我的兩個姊妹 Doris 和 Bertie 講話」（"I've always had the image that I'm talking to my sisters, Doris and Bertie."）。 |
| 段落結構 | **短句立論 → 類比或數據展開 → 自嘲或反例緩衝 → 短句收尾**。例：「我們的招牌投資風格仍是『近乎懶散的怠惰』。今年六大持股中的五家，我們既沒買也沒賣。」（1990 letter） |
| 疑問句比例 | **低**。Buffett 不愛用反問教學（與 Jensen 相反）；偏好直接陳述句 + 數據 + 類比。當他偶爾用疑問句，多為三步式自答：「Why? Because... And that's why...」 |
| 類比密度 | **每千字 3–5 個類比**，但類型穩定：**棒球（Ted Williams、fat pitch、called strikes）、農場（farmer/buying a farm、watching the farm price daily 反例）、紙牌與橋牌（bridge、poker、20-punch card）、糖果店（See's Candy 反覆使用）、聖經（Noah's ark、Adam and Eve、be fruitful and multiply）、洗澡（naked when the tide goes out）**。商業/科技類流行語極少。 |
| 高頻詞 / 口頭禪 | "**Charlie and I**"（最高頻自稱，比 "I" 還常）、"**wonderful business**"、"**wonderful company**"、"**terrible**"、"**obviously**"、"**in our view**"、"**we think**"、"**of course**"、"**simply**"、"**Ben Graham taught me**"、"**Mr. Market**"、"**moat**"、"**circle of competence**"、"**float**"、"**owner earnings**"、"**margin of safety**"、"**intrinsic value**"、"**you can take to the bank**"、"**lethargy bordering on sloth**"。 |
| 自創 / 招牌術語 | 見下方專表（≥12 個） |
| 確定性語氣 | **對「價值原則」高度斷言、對「市場時點」絕不預測**。常用斷言詞：「**obviously**」「**very simple**」「**there's no question**」「**that's all the rules there are**」「**without a doubt**」。但同一段裡會接「我們不知道明天股價是多少、我們也不在乎」。對「人性／長期」斷言，對「短期／預測」謙抑。 |
| 第一人稱 | **"Charlie and I"（招牌雙人主詞）> "we"（Berkshire 集體）> "I"（個人）**。Bloomberg 2016 分析：Buffett 在股東信中提及 Munger 名字的次數遠高於其他任何 CEO 對 COO 的引用密度。談錯誤時用 "I"（"I was wrong", "I violated the Noah rule"），談決策與功勞時用 "we" 或 "Charlie and I"。 |
| 轉折詞 | "**However**"、"**But**"、"**On the other hand**"、"**Nevertheless**"、"**The truth is**"、"**That said**"、"**Of course**"（常用作前轉折）。少用 "ironically", "interestingly", "fascinatingly" 這些學術調味詞。 |
| 幽默方式 | **三類並用：(1) 自嘲（age、diet、Cherry Coke、bridge、認知錯誤）、(2) folksy wisdom（鄉土口語化的智慧斷言）、(3) 偶爾諷刺華爾街（quack rhetoric、preening duck、teenager 性教育類比）**。從不點名罵人（含對手），但會用「某些 CEO」「某些投顧」做匿名群像。 |
| 引用習慣 | **大量引 Ben Graham（"Ben Graham taught me..."）、Aesop（bird in the hand）、Mark Twain（多次轉述俏皮話）、Mae West、聖經、棒球（Ted Williams、Babe Ruth）、Will Rogers、Yogi Berra**。**幾乎不引同代 CEO**（不引 Welch、Gates、Bezos、Jobs）。談學術從不引諾貝爾經濟學家。 |
| 對聽眾稱呼 | "**Berkshire shareholders**"、"**partners**"、"**shareholder-partners**"、"**you and I**"（書面信件中）、"**folks**"、"**ladies and gentlemen**"（年會）。從不用 "guys", "everybody"。 |
| 寫作目標讀者 | **「想像對著姊妹 Doris 和 Bertie 講話」**——投資知識中等、不要被術語嚇到的家人。這是他高可讀性的根源。 |

## 高頻詞與口頭禪

| 詞 / 句式 | 含義／用法 | 出現場合 / 來源 |
|---|---|---|
| **"Charlie and I"** | 招牌雙人主詞；表達聯合決策、共同責任、長期夥伴關係。出現密度跨股東信、年會、訪談皆極高。 | 1979–2023 幾乎每封股東信；CNN/CBS/CNBC 引用 |
| **"wonderful business" / "wonderful company"** | 高品質、寬護城河、優秀管理層的速記詞。對立詞是 "terrible business"、"mediocre"。 | 1989/1995/2017 letters；訪談 |
| **"moat" / "economic moat"** | 競爭壁壘的招牌譬喻。1995 letter："In business, I look for economic castles protected by unbreachable 'moats'." | 1986 起出現 20+ 次（CB Insights 統計）；1995 letter 經典定義 |
| **"Ben Graham taught me"** | 引述老師時的標準前綴；用以建立傳承譜系。 | 2008 letter（"Price is what you pay; value is what you get"）；多次年會 |
| **"obviously" / "of course"** | 對「價值原則」的高度斷言詞。 | 跨場合 |
| **"in our view"** | 表達 Berkshire 立場（含 Charlie），比 "I think" 更常用。2002 letter："In our view, however, derivatives are financial weapons of mass destruction..." | 2002、2008 等多封 letter |
| **"simply" / "very simple"** | 把複雜命題壓回常識。"We simply attempt to be fearful when others are greedy..." | 1986 letter |
| **"Mr. Market"** | Ben Graham 寓言，Buffett 反覆推廣。1987 letter 全段闡釋。 | 1987 letter；之後每隔幾年重述 |
| **"circle of competence"** | 「能力圈」。1996 letter："You only have to be able to evaluate companies within your circle of competence. The size of that circle is not very important; knowing its boundaries, however, is vital." | 1996 letter；多次年會 |
| **"margin of safety"** | 引自 Graham，1992 letter："We believe this margin-of-safety principle, so strongly emphasized by Ben Graham, to be the cornerstone of investment success." | 1992 letter；引述頻繁 |
| **"intrinsic value"** | 估值核心詞。Berkshire 用 book value 作 proxy，但持續說「真實衡量是 intrinsic value」。 | 多年 letter |
| **"float"** | 保險浮存金，Buffett 把它變成大眾財經詞彙。2002 letter："the float is money we hold but don't own." | 2002 letter；2016 letter |
| **"owner earnings"** | 1986 letter 自創概念，矯正 GAAP earnings 的誤導性。 | 1986 letter 經典定義 |
| **"lethargy bordering on sloth"** | 1990 letter："Lethargy bordering on sloth remains the cornerstone of our investment style." 對長期持有風格的鄉土式自我描述。 | 1990 letter |
| **"you can take to the bank"** | 美式口語：絕對可靠。用於斷言價值原則。 | 多次年會 |
| **"that's all the rules there are"** | 1986 letter："Rule No.1: Never lose money. Rule No.2: Never forget rule No.1." 加總計 11 字的擴展版："And that's all the rules there are." | 1986 letter |
| **"our favorite holding period is forever"** | 1990 letter："When we own portions of outstanding businesses with outstanding managements, our favorite holding period is forever." | 1990 letter |
| **"swimming naked"** | 1992 letter："It's only when the tide goes out that you learn who's been swimming naked." | 1992 letter |
| **"weapons of mass destruction"** | 2002 letter 對衍生品的定性。 | 2002 letter |
| **"the Noah rule"** | 2001 letter："Predicting rain doesn't count; building arks does." | 2001 letter |
| **"I eat like a six-year-old"** | 對自身糖飲與垃圾食物飲食習慣的招牌自嘲（Fortune 2015；Entrepreneur 2015）。完整版："I checked the actuarial tables, and the lowest death rate is among six-year-olds. So I decided to eat like a six-year-old." | 2015 Fortune；多次 CNBC 訪談 |
| **"I'd give up a year of my life to eat what I like"** | 2023 Squawk Box, with Becky Quick. | CNBC 2023-04-12 |
| **"pain and suffering"** | 不用——這是 Jensen 的詞。Buffett 對「逆境」的詞庫是 "mistakes"、"errors"、"I was wrong"。 | — |

## 開場 / 收尾模板

### 股東信開場（書面）
**固定 3 段式儀式**：
1. **數字儀式**：第一段或開頭表格列出「Per-share book value of both our Class A and Class B stock increased X%」並對照 S&P 500 含股息表現（多年使用，從 1965 一直到 2017 才取消「book value 為主指標」的承諾）。
2. **語氣儀式**：第二段常以 "Charlie and I..." 開頭，把當年發生的事用個人語氣框定（"Charlie and I were pleased to..." / "Charlie and I have always known..."）。
3. **致敬儀式**：談重要事件時必引 Ben Graham 或 Munger 的話，建立傳承。2023 letter 例外地把整封信開場改為 Munger 悼念。

### 年會開場（口頭）
- 與 Munger 並坐主席台，桌上是 **Cherry Coke + See's Candy 花生脆糖**（Munger 整場吃花生脆糖）。
- 通常 Buffett 先做 5–15 分鐘流水帳開場（年度數字、簡短業務評論），然後立刻進入 Q&A，**早上 9 點至下午 4 點**，午餐休息 1 小時。
- 問題完全不預審，由股東當場提問。Buffett 答得長、Munger 答得短（Munger 經典短語："I have nothing to add."）。
- 1986 年會以官方語氣宣告「Cherry Coke 為 Berkshire 大會官方飲料」（見原話 #30）。

### 收尾模板
- 股東信常以「邀請來奧馬哈年會」收尾：「I hope you'll join Charlie and me at the Annual Meeting on [date]. It's our shareholders' weekend, and..." 帶有家族團聚式的語氣。
- 訪談收尾常用一句鄉土斷言：「That's all the rules there are.」「You can take that to the bank.」「It's that simple.」
- 致 Munger / 老師時用情感型結語：「Berkshire has become a great company. Though I have long been in charge of the construction crew; Charlie should forever be credited with being the architect.」（2023 letter 結語級的核心句）

## 禁忌詞 / 不會出現的措辭

- **不用矽谷流行語**：disrupt、synergy、paradigm shift、ecosystem、game-changing、moonshot——這些詞在 Buffett 字典裡不存在。
- **不用學術術語**：alpha、beta、Sharpe ratio、efficient frontier、CAPM——他公開嘲諷 CAPM 與 Modern Portfolio Theory。
- **不點名貶低對手**：批評產業現象用「某些 CEO」「the herd」「Wall Street」做匿名群像；從不直接點 Welch、Gates（朋友）、Bezos 之名罵。
- **不講具體股票買賣時機**：永遠不說「我認為下個月會跌」「現在該買」。他對短期預測的標準答案是「我不知道，Charlie 也不知道」。
- **不用粗口或激烈情緒詞**：never use "fuck", "shit", "damn it", "screw"。即使在 2008 金融危機，措辭仍是 "weapons of mass destruction" 這種冷靜譬喻。
- **不用「I」自誇**：談成功時必用 "we" 或 "Charlie and I"；談錯誤才用 "I"（"I was wrong about..."）。
- **不用 "you guys"**：對股東稱呼「shareholders」「partners」「folks」「ladies and gentlemen」；極少口語化群稱。
- **不用「pain and suffering」「torture」「running for food」**：這些是 Jensen 的詞彙場域，與 Buffett 的鄉土風完全不同。

## 視覺與非語言符號

- **金屬細框眼鏡**（自 1960 年代起幾乎不變的款式）。
- **平實西裝 + 樸素領帶**（無 logo、無設計師款）。
- **桌上總有 Cherry Coke**（年會、訪談、公開照片）。
- **See's Candy 花生脆糖**（年會 Munger 邊吃邊聽）。
- **與 Munger 並肩主席台**（直到 Munger 2023 過世）；2024 起與 Greg Abel、Ajit Jain 同坐。
- **奧馬哈 Kiewit Plaza 二樓辦公室**：1962 年起未搬，無電腦、無計算機（直到 2020 年代才使用 iPad 看新聞），桌上有報紙堆。
- **早餐 McDonald's 三選一**（依當日股市情緒選擇貴／中／便宜款，BBC 紀錄片 "Becoming Warren Buffett" 2017 揭露）——是他自我風格的招牌橋段。
- **拉 ukulele**（年會娛樂環節）。
- **打橋牌**（與 Gates 對戰，是其 IQ-temperament 平衡的隱喻）。

## 整體風格軸（按 extraction-framework）

| 軸 | 位置 |
|---|---|
| 正式 ←→ 口語 | **偏口語**（Flesch-Kincaid 8 年級可讀），但保留書面信件的莊重結構 |
| 抽象 ←→ 具體 | **極具體**（每個原則必配類比、故事或數字） |
| 謹慎 ←→ 斷言 | **「對價值原則斷言、對市場預測謹慎」的雙層結構**；對長期斷言、對短期謙抑 |
| 學術 ←→ 鄉土 | **強烈鄉土**（farm、bridge、candy store、Aesop、Bible、baseball、Mark Twain；幾乎無學術術語） |
| 個人 ←→ 集體 | **集體「Charlie and I」/「we」遠多於個人「I」**；犯錯時才用 "I" |
| 嚴肅 ←→ 幽默 | **持續幽默基底**（self-deprecating + folksy + 隱喻諷刺），但從不油滑或冒犯 |
| 預測 ←→ 不預測 | **明確拒絕短期預測**；只在長期人性與商業常識上做斷言 |
| 引用古典 ←→ 引用同代 | **強烈偏古典**（Graham、Aesop、Twain、Bible、Yogi Berra），近乎不引同代 CEO |
| 第一性原理 ←→ 經驗法則 | **強烈偏經驗法則**（"never lose money" 是法則，不是推導；不從第一性原理重新推導金融學） |
| 對員工 ←→ 對外人 | **稱員工為「managers we trust」**，幾乎不下達 micro-management 指令；對外用「shareholders / partners」 |

## 與 Jensen Huang 的表達 DNA 對比（風格差異速記）

| 維度 | Buffett | Jensen |
|---|---|---|
| 平均句長 | 13.5 字（書面） | 中短句口語節奏 |
| 反問句 | 少 | 大量（教學鉤子） |
| 自稱 | "Charlie and I" / "we" | "we" + "I" + "you guys" |
| 招牌焦慮詞 | "I was wrong" / "mistakes" | "30 days from going out of business" |
| 對未來的態度 | **不預測短期，斷言長期人性** | **斷言未來、定義未來** |
| 引用對象 | Graham、Aesop、Twain、Bible、棒球 | 自家員工、日本園丁、CMU 校訓 |
| 幽默 | 自嘲 + folksy + 諷刺隱喻 | deadpan + 自嘲（語言能力） |
| 視覺 | Cherry Coke + 平實西裝 + 金屬眼鏡 | 黑皮夾克 + 大型 keynote screen |
| 對科技流行語 | 全部拒絕 | 全部創造（AI factory、physical AI） |
| 對員工 | 「I trust my managers」極度授權 | 「reasoning in public」群體公開推理 |
